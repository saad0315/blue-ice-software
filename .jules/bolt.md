## 2024-05-15 - [Dashboard Data Derivation]
**Learning:** In the basic dashboard route (`GET /`), `orderCount`, `activeOrderCount`, and `totalRevenue` can be derived in-memory from a single `db.order.groupBy` query (`orderStatusDistribution`) combined with `_sum: { totalAmount: true }`. This eliminates 3 separate database calls (`db.order.count()`, `db.order.count({ where: ... })`, `db.order.aggregate({ _sum: ... })`) that were running in parallel. This is a common pattern in this codebase where multiple aggregates on the same table can be consolidated into a single group by and summed in code.
**Action:** When calculating metrics, check if a groupBy query is already returning the necessary data. If so, derive metrics in code to reduce the number of queries. Ensure the groupBy queries include necessary fields (e.g., `_sum`).
