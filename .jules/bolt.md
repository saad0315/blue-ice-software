## 2025-03-09 - Consolidate Parallel Aggregate Queries with GroupBy in Driver Stats
**Learning:** In `getDriverStats` (`src/features/driver-view/queries.ts`), there were 4 parallel `db.order.aggregate` calls to compute financial totals by `PaymentMethod` alongside 5 `db.order.count` calls for different order statuses. This created significant database roundtrips and overhead. Grouping the orders by `['status', 'paymentMethod']` consolidates these 9 queries into a single query and we can derive the totals via in-memory reduction without affecting correctness or schema limits.
**Action:** Always check parallel `.aggregate()` and `.count()` requests on the same database table/filters, as they can usually be grouped by common dimension keys (e.g., status, payment method) and simplified into a single `db.model.groupBy` database call, saving substantial backend cycles.
