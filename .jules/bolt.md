## 2024-05-15 - [Consolidating Driver Queries for Performance Optimization]
**Learning:** Consolidating multiple `db.order.count` queries by specific statuses or payment methods into a single `db.order.groupBy` query and performing sum/count derivations in-memory reduces the total number of database calls significantly when generating driver statistics pages (`getDriverStats` and `getDriverDetailStats`), avoiding unnecessary overhead of parallel redundant connections for data that shares a similar bounding logic (date and driver criteria).
**Action:** When working on analytical or summary endpoints that retrieve counts grouped by different enum values (e.g., status, payment method), use a single `groupBy` or `aggregate` request with appropriate grouping keys instead of parallel `count()` queries per filter. Derive individual values in-memory to reduce connection and processing overhead on the database layer.
